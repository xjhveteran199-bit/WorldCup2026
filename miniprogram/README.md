# 硅基看球 · 微信小程序版（Phase B · 纯统计版）

2026 美加墨世界杯**数据预测**小程序，原生框架，与网页版共享 `core/` 统计引擎。

> ⚠️ **重要（v1.0.1 被驳回的教训）**：个人主体小程序**不得含生成式 AI/深度合成功能**（AI问答/换脸/绘画等）。v1.0.1 因内置「AI 大模型战术分析」被判「深度合成技术，个人主体未开放服务类目」驳回。
> 自 v1.0.2 起，小程序**已彻底移除 AI 功能**（设置页、llm.js、战术分析全部删除），只保留纯数学统计：Elo+双泊松预测、实时评分、冠军模拟、分享卡片。网页版不受此限制，AI 功能照常保留。**切勿再往小程序加任何 LLM/AI 生成功能。**

## 一、本地运行

1. 用**微信开发者工具**打开本 `miniprogram/` 目录
2. 首次需在 `project.config.json` 里把 `appid` 改成你自己的小程序 AppID（在微信公众平台 → 开发管理 → 开发设置里查）
3. 编译预览 → 真机扫码测试

## 二、提审前必做的后台配置（微信公众平台 mp.weixin.qq.com）

### 1. request 合法域名（开发管理 → 开发设置 → 服务器域名）
纯统计版只需**一个**域名（用于拉取每天自动更新的比分数据）：

```
https://worldcup2026-blond.vercel.app
```

> AI 已移除，原来的 5 个 LLM 域名不再需要。

**数据自动更新机制（无需重新提审）**：小程序启动时从 `worldcup2026-blond.vercel.app/data.json` 拉取最新比分，缓存到本地，下次冷启动生效（stale-while-revalidate）；拉取失败则用打包的 `utils/data.js` 兜底。网页版的每日定时任务会同步更新这个 data.json，所以**小程序发布一次后，后续比分更新无需再提审**。若 Vercel 在国内访问不稳定，用户会看到打包数据（最近一次发版时的数据），功能不受影响。

### 2. 基本信息
- **名称**：`硅基看球-2026美加墨`（备选 `章鱼算球·2026美加墨`）
  - ⚠️ 名称字段**禁止**出现「世界杯」（FIFA 注册商标，个人主体必被驳回）；简介和页面内文案可正常使用
- **简介**：用 Elo 评分与泊松模型预测足球赛事胜负概率，模拟万届赛事冠军走势。数据娱乐，仅供参考。

  - ⚠️ **切勿选择「体育赛事」相关类目**，会触发竞猜/博彩审查

### 3. 头像
🐙 章鱼 + 火焰红配色，与网页版/小红书账号视觉统一。

## 三、合规要点（个人主体）

- **BYOK 模式**：小程序自身不提供 AI 服务，用户填自己的大模型 API Key，AI 内容由用户自有密钥调用第三方生成 → 降低生成式 AI 算法备案审查风险。审核被问到时，定位为「数据分析客户端工具」。
- **全站文案禁用**：竞猜、投注、赔率、博彩、必胜、稳赚等词。统一用「数据模型分析」「娱乐向预测」。
- 每页底部均有免责声明：「预测仅供娱乐参考，不构成任何竞彩建议」。

## 四、数据更新

- 数据内置于 `utils/data.js`（从 `core/data.js` 复制）。**小程序数据更新需重新提审**（不像网页 push 即生效）。
- 更新流程：把最新的 `core/data.js` 重新复制到 `miniprogram/utils/data.js` → 微信开发者工具上传新版本 → 提交审核。
- 网页版每天自动更新（定时任务），小程序建议每隔几天或关键节点（如小组赛结束、淘汰赛开始）批量更新一次提审。

## 五、目录结构

```
miniprogram/
├── app.js / app.json / app.wxss      全局
├── project.config.json                项目配置（填你的 appid）
├── utils/
│   ├── engine.js   ← core/engine.js 零改动复用（统计引擎）
│   ├── data.js     ← core/data.js 零改动复用（48强+赛程）
│   └── llm.js      ← wx.request 版多渠道 LLM（非流式）
└── pages/
    ├── predict/    对阵预测（概率/热力图/六维/AI/分享卡片）
    ├── fixtures/   完整赛程（点击直达预测）
    ├── sim/        冠军模拟器（蒙特卡洛万届）
    ├── doc/        模型方法论
    └── settings/   AI 大模型 BYOK 设置
```

## 六、与网页版的差异

| 项 | 网页版 | 小程序版 |
|---|---|---|
| AI 输出 | SSE 流式 | wx.request 非流式（一次性返回，带 loading） |
| LLM 渠道 | 含 Gemini | 仅国产 5 家（域名可备案） |
| 数据更新 | git push 即生效 | 需重新提审 |
| 引流 | 截图 + 链接 | onShareAppMessage 转发好友/群 + 朋友圈分享 |
| 六维展示 | Canvas 雷达图 | 原生对比条（更稳） |

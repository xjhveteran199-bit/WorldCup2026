# 🐙 硅基章鱼 · 2026美加墨世界杯AI预测

**碳基看球，硅基算球。** 统计模型 × AI 大模型双引擎的世界杯比赛预测工具。

## 双引擎架构

**引擎 1 — 本地统计模型**（免 Key、秒出、可复现）
- Elo 胜负期望（eloratings.net 体系，含东道主 +100 加成与近期状态修正）
- 双泊松进球模型 `λ = 1.30 × e^(0.0011·Δ)` + Dixon-Coles 低比分修正（ρ = −0.13）
- 输出：胜平负概率、9×9 比分矩阵、最可能比分、淘汰赛点球晋级概率

**引擎 2 — LLM 战术分析层**（填 Key 解锁）
- 多渠道统一 OpenAI-compatible 接入：DeepSeek / Kimi / 智谱 GLM / 通义千问 / MiniMax / Gemini
- 阵型相克、教练斗法、关键对位、X 因素，流式输出
- 对统计概率做**有界修正（±8pt）**，双引擎结果并排展示

## 功能

- ⚔️ 任意对阵预测（48 强全数据：Elo、FIFA 排名、阵型、教练、核心球员）
- 📅 104 场完整赛程（北京时间），点击直达预测，已赛比分锁定
- 🏆 冠军模拟器：蒙特卡洛模拟 10000 届世界杯
- 📸 一键生成 1080×1440 小红书分享卡片
- 🔬 模型方法论科普页

## 结构

```
core/data.js    48 强数据 + 赛程（双端共享，赛程中热更新）
core/engine.js  统计引擎（纯函数，node core/engine.js 跑自测）
core/llm.js     多渠道 LLM 封装
index.html      网页版（零依赖零构建）
miniprogram/    微信小程序版（Phase B）
```

## 运行

直接用任何静态服务器打开，如 `python -m http.server 8642`。

数据基线：Elo 2026-06-10 · FIFA 排名 2026-06-11。赛程中手动更新 `core/data.js` 的 `results` 与 `form`。
